# Contributing to LazyCode AI

Thank you for your interest in contributing to LazyCode AI! 🎉

We welcome bug fixes, new features, documentation improvements, UI enhancements, and suggestions.

## How to Contribute

### 1. Fork the Repository

Fork the repository on GitHub to create your own copy.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR-USERNAME/lazycode-ai.git
cd lazycode-ai
```

Replace `YOUR-USERNAME` with your GitHub username.

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Set Up the Project

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install flask requests
```

Install Ollama and download the required model by following the instructions in `README.md`.

### 5. Make and Test Your Changes

Make your changes and test the application locally before submitting them.

### 6. Commit Your Changes

```bash
git add .
git commit -m "Describe your changes"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Open a Pull Request

Open a pull request on GitHub and explain what you changed and why.

## Contribution Guidelines

- Keep changes focused and easy to review.
- Write clear commit messages.
- Test your changes before submitting them.
- Do not commit virtual environments, API keys, passwords, or private configuration files.
- Be respectful and constructive when communicating with other contributors.

## Need Help?

Open an issue in the GitHub repository to report a bug, suggest a feature, or ask a question.

Thank you for helping improve LazyCode AI! ❤️
